# Notificaciones Push con Firebase

Este proyecto es una **aplicación de demostración en Android** que implementa la funcionalidad de **notificaciones push** utilizando **Firebase Cloud Messaging (FCM)**.  

La app está configurada para recibir y gestionar mensajes enviados directamente desde la **consola de Firebase**, convirtiéndose en un **punto de partida ideal** para desarrolladores que deseen integrar notificaciones push de forma **robusta y eficiente** en sus aplicaciones.


## Características principales

-  **Integración con Firebase**: Configuración completa del proyecto Android con Firebase.  
-  **Servicio de mensajería**: Implementación de `MyFirebaseMessagingService` para manejar mensajes entrantes.  
-  **Recepción de notificaciones**: Soporte tanto en **primer plano** como en **segundo plano**.  
-  **Gestión de tokens**: Registro del **token FCM** de cada dispositivo, mostrado en **Logcat** para pruebas.
